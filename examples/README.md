# Worked examples

Each folder contains an HTML snippet and an SCSS reference implementation. These are educational samples, not a compiled component library. Custom-property values are illustrative; replace them with your project's tokens.

- [Button](button/) — semantic modifier and native disabled state
- [Card](card/) — independent modifiers and custom-property variations
- [Navigation](navigation/) — accessibility state without modifier inflation
- [Rich text](rich-text/) — a deliberate exception for authored or generated prose
