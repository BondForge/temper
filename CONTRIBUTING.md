# Contributing to Temper

Thanks for your interest. Temper is a small, opinionated set of architectural conventions, not a feature-collection 
exercise.

Before proposing a change, explain the problem, include a minimal HTML/SCSS example, identify how the proposal improves 
clarity or maintainability, and describe any tradeoffs. Keep documentation and the agent guide aligned when normative 
guidance changes.

For substantive changes, open a discussion or issue before a large pull request. Be respectful of other styling 
approaches; Temper is not a claim of universal superiority.

Please do not include private BondForge product code, data, or credentials in examples.
